# Nuxt storefront — end-to-end / integration scripts (IMP-009)

Manual, scoped verification tooling (not part of `vitest run`). All of it runs against a **mock API or a
`_testing` database only** — never DEV or production data.

| Script | What it proves | Needs |
|---|---|---|
| `mock-api.mjs` | Fixture stand-in for the public Laravel API; records every request (method, path, query, cookie, `Authorization`, `X-Locale`) on `:8001`. `GET /__clear` resets that log — any check that asserts over the **whole** log must call it first (a long-lived mock otherwise contains traffic from earlier browser runs). | node |
| `smoke.mjs` | Built/dev Nuxt server: status, `<title>`, canonical/OG, JSON-LD, 404s, robots/sitemap, **SSR sends only GET and never a cookie/Authorization header**, SSR never calls `/auth/*`, SPA-owned paths fail closed. | mock on :8000 + Nuxt on :3000 |
| `i18n-ssr.mjs` | Multilingual SSR + SEO + pagination + store-locator privacy: per-language `<html lang>`/`og:locale`/canonical/hreflang, hostile/inactive `?lang=` ignored, 60 concurrent mixed-language requests with no cross-request leakage, `X-Locale` sent and SSR still anonymous, `?page=N` SSR + self-canonical + `rel=prev/next`, filtered `noindex`, beyond-last 404, locator SSR free of phone/referral, sitemap alternates, `/healthz`. | mock on :8000 (+ log on :8001) + Nuxt on `NUXT_URL` |
| `browser-i18n.mjs` | Real Chromium: hydration in 4 languages × 4 page types (0 mismatches/0 page errors), `?lang=` persisted to localStorage **and** the `pc-locale` cookie, next visit server-rendered in that language, language switcher updates lang/title/canonical/hreflang/URL without reload, pagination in-app + back button, store locator restores phone/referral after hydration. | Playwright image + mock + Nuxt (`nuxt dev` prints mismatch details) |
| `browser.mjs`, `browser2.mjs`, `hyd.mjs` | Real Chromium: **0 hydration mismatches** on every SSR page (incl. 404 states), stored locale/theme/cart adopted after hydration, SPA hand-off is a full-page navigation, signed-in visitors re-fetch actor-specific data. | Playwright image + mock + Nuxt |
| `sanctum.mjs` | Real Laravel (`APP_ENV=testing`, `primeclassy_testing`) behind the Nuxt same-origin proxy: csrf-cookie, 419 without `X-XSRF-TOKEN`, login, session cookie flags, SSR stays anonymous with a valid session, RBAC 403s, logout. Seed two users first and delete them afterwards. | Laravel + Nuxt dev in one network namespace |
| `dev-proxy.mjs` | **Test fixture**: local, production-shaped reverse proxy on one origin (Nuxt + SPA build + Laravel) implementing only the documented route table. Passes response headers through untouched (`x-pc-renderer`), and can serve a byte-changed `/sw.js` or simulate a total outage. Control endpoints live on `PORT+10`: `/__routes`, `/__reset`, `/__sw-next`, `/__down`, `/__up`. `NUXT_ENABLED=0` = rollback mode (SPA owns every URL). | built SPA (`frontend/dist`), built or dev Nuxt, mock API |
| `proxy-routing.mjs` | Deployment readiness: which runtime answers each path (Nuxt vs SPA vs Laravel), `x-pc-renderer` forwarding, `/page/*` real 404 with marker, `/sw.js` + `/config.js` + manifest from the SPA build, `/_nuxt/*` from Nuxt, `/api`/`/up` proxied, and the **rollback drill** (`NUXT_ENABLED=0`). | `dev-proxy.mjs` on :8080 (+ rollback on :8081) |
| `browser-pwa.mjs` | Real-Chromium PWA: SW registration/activation/control, **cache isolation** (a Nuxt SSR page never replaces the cached SPA shell; no `/api`, `/sanctum`, `/storage`, `/config.js`, `/_nuxt` in the cache), offline navigation (true socket-level outage), and **update behaviour** (a byte-changed worker waits; only an explicit `SKIP_WAITING` activates it). | Playwright image + `dev-proxy.mjs` (built SPA + built Nuxt) |

Run recipes are in `docs/20-IMP009-NUXT-STOREFRONT.md` §10c.
